# ArogyaAI - Smart Health Kiosk

**ArogyaAI** is a bilingual (Tamil & English) smart health kiosk web application that integrates emergency services, patient appointment booking, and live IoT-based health monitoring. This project is designed for hospitals, clinics, and health centers to provide a digital-first patient experience.

---

## Features

### 🌐 Frontend
- Bilingual interface (Tamil & English)
- Emergency button with live location detection
- Nearby ambulance display
- Quick appointment booking
- Live IoT simulation for heart rate, temperature, SpO₂, and risk %

### 🩺 Appointment System
- Voice-based Tamil booking
- Patient registration form with automatic OTP verification
- Multi-doctor management
- Conflict detection for overlapping appointments
- PDF appointment slip generation
- SMS and WhatsApp notifications (simulated)

### ⚡ IoT & AI
- Real-time IoT monitoring simulation
- AI guide for health tips
- AI-based doctor recommendation (planned backend integration)
- Smart triage logic

### 🏥 Admin Dashboard
- View all appointments
- Calendar with blocked/available slots
- Doctor availability schedule
- Auto-generated appointment IDs
